To add new music to the game:

1. Convert that music into xa format and place the .xa files in this directory (using psxavenc recommended)
2. Manually update CDXA00_EXT.cvs with each new entry. Each entry should look like this:

1,xa,ext/<song.xa>,600,1,<xa channel>

where
  <song.xa> is the name of an .xa file in this directory
  <xa channel> starts at 5 for the first entry, goes down to 0, then goes from 0-7, and from 7-0, repeating
        (5, 4, 3, 2, 1, 0, 0, 1, 2, 3, 4, 5, 6, 7, 7, 6, 5, 4, 3, 2, 1...)

3. run pack_xa.sh in the above directory
4. You might have to manually update the NumberSongs equ in ComboKyo.asm with the amount of new tracks
